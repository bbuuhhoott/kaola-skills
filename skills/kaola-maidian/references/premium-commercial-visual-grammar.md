# 高级商业卖点视频视觉语法

## 核心判断

高级感来自“可信的商业摄影控制力”，不是特效数量。把环境压力、产品功能和可观察结果组织成完整因果链，让观众既看到材质与结构，也理解卖点。

默认母结构：

```text
暗场揭幕 → 环境压力或任务出现 → 功能介入 → 微距观察变化 → 使用结果 → 压力与特效退场 → Hero packshot
```

## 七条基线

1. **建立可控压力场**：使用可说明来源和方向的雨、水、风、热、声、光、冲击、摩擦、任务负载或机械动作。不要无因出现粒子和能量罩。
2. **写完整因果动作链**：写清元素从哪里出现、作用于哪里、如何变化、沿什么方向结束。优先使用撞击、分裂、弹开、滚落、扩散、导出、衰减、收束和退开等动词。
3. **使用景别阶梯**：完整轮廓建立身份 → 中近景展示作用点 → 极端微距观察材质或结构 → 回到完整产品。微距必须服务卖点，不做无意义细节巡游。
4. **让光线揭示产品**：优先侧逆光、轮廓光、掠射光、受控反射和明暗收束，用光揭示纹理、硬挺度、曲面和边界；避免满屏霓虹和统一蓝光滤镜。
5. **让物理元素承担转场**：使用水膜遮挡、水珠轨迹、气流方向、冲击闪白、结构动作、屏幕响应或声音节拍做 match cut。不要依赖模型生成文字转场。
6. **让产品始终占据视觉主位**：挑战元素围绕产品发生，不能长时间遮住识别点，也不能让人物表演、环境奇观或特效抢走主体。
7. **让效果退场**：结尾减弱并移开水、风、热流、声场、光带或粒子，回到完整、稳定、清晰的 Hero packshot；Logo、结构和材质边界保持稳定。

## 不同品类的物理语言

| 品类 | 优先使用 | 避免机械套用 |
| --- | --- | --- |
| 户外服装 | 暴雨、定向水流、风场、织物受力、水珠滚落、接缝和拉链微距 | 无依据的分子结构、能量护盾、绝对不渗水 |
| 科技/3C | 真实任务响应、界面状态、热流导出、光学路径、机械动作、声场变化、有依据的结构示意 | 通用蓝色 HUD、代码雨、芯片爆炸、无依据跑分和内部结构 |
| 耳机/音频 | 环境声层前后对照、声场隐喻、结构贴合、佩戴结果 | 把声波屏障冒充真实检测、虚构频响参数 |
| 家电 | 气流、热流、尘屑或水汽的进入与导出、真实操作结果 | 无来源粒子、夸张吸力或温度数字 |
| 鞋类 | 落地冲击、压力扩散、回弹、湿滑表面水花 | 超物理形变、危险动作保证安全 |
| 美妆个护 | 液体铺展、表面光泽、细腻度、使用前后状态 | 虚构皮肤内部结构、临床数字和功效时长 |

科技产品也要遵循同一摄影逻辑，但把“暴雨压力”替换成该产品真正面对的任务或状态。先拍真实产品和任务，再决定是否需要数据、光线或结构示意；科技感是精确、克制和可观察，不是默认使用激光与 HUD。

## 提示词结构

### 1. 核心创意

写清时长、画幅、品类、核心卖点、真实压力场、商业摄影质感、声音弧线和不采用的廉价表达。

### 2. 带时间码的画面过程

每段至少写清：

- 景别和产品状态。
- 挑战元素或任务从哪里出现。
- 具体作用点。
- 产品或环境发生的可观察变化。
- 运镜和光线。
- 用什么画面动作转场。
- 本段如何结束并衔接下一段。

### 3. 生成与事实边界

- 锁定产品轮廓、比例、颜色、Logo、结构、材质边界和配件数量。
- 未经依据不得生成参数、认证、内部结构、测试等级或绝对效果。
- 除产品自身徽标外，不生成字幕、乱码、随机文字、角标或水印。
- 禁止廉价 CG、随机粒子、过度霓虹、产品漂移和特效遮挡主体。

## 生成拆分

整片创意可以有 6–7 个短视觉节拍，但不要把复杂 15 秒整片一次性交给视频模型。按 3–4 个语义连续片段生成：

1. 揭幕与压力建立。
2. 核心功能作用与微距证据。
3. 使用结果与产品整体状态。
4. 必要时单独生成 Hero packshot。

统一身份锚图、色彩、光线方向、环境物理和声音逻辑后再组装。只重做失败片段。
