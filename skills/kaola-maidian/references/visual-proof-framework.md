# 卖点视觉论证框架

## 先写论证链

每个卖点先完成一行：

```text
用户问题 → 产品功能 → 可观察变化 → 用户利益 → 依据
```

示例：

```text
通勤噪音干扰 → 主动降噪 → 开启后环境噪声层明显下降 → 更容易专注 → 用户提供的主动降噪规格
```

“更高级”“黑科技”“旗舰体验”等词本身不是可拍卖点。把它们改写成具体状态变化，或删除。

## 选择表现类型

| 类型 | 适合内容 | 规则 |
| --- | --- | --- |
| 直接实验 | 防水、防风、防滑、缓震等外部性能 | 展示挑战、作用过程和可观察结果；不要把创意演示冒充标准测试 |
| 前后对照 | 降噪、散热、稳定、速度等状态差异 | 固定构图与变量，只改变功能开关或产品介入状态 |
| 机制示意 | 有资料支持的流道、层次、传感或结构 | 标注为示意，结构与参数必须有来源 |
| 感知隐喻 | 安静、轻盈、沉浸、舒适等主观体验 | 在方案中标明是创意表达，不声称它证明量化效果 |
| 使用结果 | 真实场景中的用户收益 | 让功能结果清楚，不让人物表演抢走产品主体 |

优先级通常是：直接可见证据 > 控制变量对照 > 有依据的机制示意 > 感知隐喻。无法严谨证明的内容可以创意表达，但必须降低断言强度。

## 卖点到视觉母题

| 品类 | 卖点 | 可见变化或母题 | 注意事项 |
| --- | --- | --- | --- |
| 服装/户外 | 防水 | 雨幕、高压水流、水珠滚落 | 不虚构防水等级；避免无依据的“完全不渗透” |
| 服装/户外 | 防风 | 风洞、烟尘或丝带沿轮廓分流 | 衣物仍需有真实受力，不要像刚体 |
| 服装/户外 | 保暖 | 冷暖环境对照、风雪与暖光包裹 | 热成像或数值需要依据；暖光可作为隐喻 |
| 服装/户外 | 透气 | 内外水汽状态变化、运动后干爽场景 | 不臆造分子级面料结构 |
| 耳机/音频 | 降噪 | 开启前后环境声层、噪音粒子被削弱 | 声波屏障是隐喻，不是科学实拍 |
| 耳机/音频 | 音质 | 分层声场、稳定波形、空间光带 | 不用画面虚构频响或解析力参数 |
| 耳机/音频 | 舒适 | 长时佩戴场景、轻量贴合、柔光包裹 | 悬浮属于隐喻；结构贴合需与产品形态一致 |
| 耳机/音频 | 续航 | 日夜或时间场景连续切换、能量轨迹 | 具体小时数必须来自资料 |
| 数码/3C | 散热 | 前后温度状态、热流被导出 | 热成像与温度数值需真实依据 |
| 数码/3C | 性能 | 同任务前后响应、数据流或速度对照 | 不虚构跑分、帧率或处理速度 |
| 鞋类 | 缓震 | 落地冲击被吸收、压力扩散和回弹 | 回弹幅度遵守材料物理，不夸张变形 |
| 鞋类 | 防滑 | 湿滑表面稳定通过、接触面水花 | 避免把危险动作包装成保证安全 |
| 美妆个护 | 保湿 | 使用前后表面光泽、水润感 | 功效时长、临床数据与皮肤结构需有依据 |

## 控制创意强度

- 让产品占据稳定主体位置，外部效果围绕产品发生，不能长时间遮住识别点。
- 让物理元素有来源、方向、作用点和消散过程，避免无因出现的粒子与光效。
- 一个镜头只展示一个主要变量。多个作用同时出现会削弱论证。
- 让最终画面回到完整产品，保持 Logo、比例、结构和材质稳定。
- 把参数、认证、型号和说明文字放在后期字幕层，不要求视频模型直接写字。
