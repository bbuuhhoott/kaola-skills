# Kaola Maidian

把“产品有什么功能”变成一条看得懂的视觉论证，而不只是好看的产品旋转。默认叙事链为：用户问题 → 环境压力或任务出现 → 功能介入 → 可观察变化 → 用户收益 → 特效退场 → 产品定版。默认追求高级商业产品摄影与真实、可控的物理演示，不把“科技感”简化为霓虹、HUD、激光和随机粒子。

## 先确定交付模式

- 用户要“创意、方案、分镜或提示词”时，完成对应方案，不发起付费生成。
- 用户要“生成、制作或直接出视频”且存在兼容工具时，先完成逐镜生成包，再按镜头生成、筛选和组装。
- 用户没有指定交付深度时，默认交付“卖点核验 + 核心创意 + 分镜表 + 逐镜提示词”，并把旁白、字幕作为可选后期层。

## 统一模型策略

- 凡需生成或编辑产品氛围图、分镜关键帧、首帧、尾帧或其他静态图像，默认使用可用的 `gpt-image-2-vip` 兼容图像能力，请求 4K。调用凭据必须由使用者通过其自身的环境变量或服务配置提供；不得读取、要求或记录他人的密钥。
- `gpt-image-2-vip` 必须传明确像素值而不是比例字符串：16:9 用 `3840x2160`，9:16 用 `2160x3840`；其他画幅使用接口文档列出的合法 4K 像素值。
- 凡需生成产品视频镜头，默认使用 `MiniMax-H3`，通过 `dm-video-generate` 执行，并固定请求 `768P` 档；测试和正式成片都不自动升级到 `2K`，最终文件默认保持 H3 原生 768P 尺寸，不放大后冒充 1080P。
- 只有用户明确指定其他模型时才覆盖默认值。默认模型不可用时，说明阻塞；不要静默切换到可灵、Seedance 或其他模型。
- 在方案、逐镜生成包和最终交付中写明实际图像模型、视频模型、模型原生分辨率与最终编码分辨率。

## 建立输入与素材映射

最低可开工信息是商品品类或名称，以及至少一个核心卖点。要达到可生成标准，尽量取得：

1. 一张或多张产品参考图，并逐张说明用途。
2. 卖点依据，如说明书、参数、认证、用户提供的正式商品文案或可观察结构。
3. 目标受众与使用场景。
4. 时长、画幅、平台、语言、风格，以及是否允许人物、旁白、字幕、拆解或剖面。

始终显式映射素材，不默认 `@图片1` 必然是产品：

```text
@图片1 = 产品正面身份锚图
@图片2 = 产品侧面结构参考
@文档1 = 已确认卖点与参数来源
```

缺少产品图时可以产出创意草案，但要用占位符并明确无法锁定产品身份。缺少卖点依据时，不补造参数、认证、材料结构或效果强度。

若用户未指定成片规格，默认使用 15 秒以内、16:9、`MiniMax-H3 768P` 的高质感商业产品片，最终编码保持模型实际返回的 768P 尺寸；平台语境明显是竖屏短视频时改用 9:16。默认不要求视频模型直接生成文字，旁白和字幕另列为后期层。

## 执行工作流

### 1. 锁定产品身份

实际查看参考图并建立身份锁定清单：整体轮廓、比例、颜色、表面材质、Logo 位置、关键结构、开合关系和不能改变的识别点。多图有冲突时，指出冲突并指定主锚图，不自行混合成新款产品。

### 2. 审核卖点真实性

把信息分为：

- **已确认事实**：参考图、说明书、参数或可信资料直接支持。
- **用户声明**：用户明确提供，但当前没有独立资料核验。
- **未知内容**：没有依据，不写成事实。
- **创意隐喻**：用于表达感受，不冒充实验结果或机制证明。

为每个卖点写出：用户问题、功能、可观察变化、用户收益和依据。若一个卖点无法形成可观察变化，先把抽象词改写为能拍摄的状态变化。

读取 [visual-proof-framework.md](references/visual-proof-framework.md)，选择直接实验、前后对照、机制示意、感知隐喻或使用结果之一。

### 3. 选择一个核心视觉母题

让每版视频只围绕一个清晰的视觉命题。优先使用真实可拍或物理可信的外部变化，如水滴、气流、声波、冲击、热流、光线、粒子或环境状态。

避免随机炫技。特效必须服务于“观众看到了什么变化，因此理解了什么好处”。使用剖面、内部流道、分子结构等机制画面前，必须有资料支持；否则改用外部效果或标注为示意。

读取 [premium-commercial-visual-grammar.md](references/premium-commercial-visual-grammar.md)，把其中“真实压力场、因果动作链、景别阶梯、材质揭示光、物理转场、效果退场、Hero packshot”作为默认高级感基线。根据品类替换物理语言：户外服装优先雨、水、风、织物受力和材质微距；科技产品优先真实任务、响应变化、热流、声场、光学、机械动作或有依据的结构示意。不得把服装的暴雨实验机械套用到科技产品，也不得给所有科技产品套通用蓝色 HUD。

多个卖点默认拆成多个单卖点版本。只有用户明确要综合版时，才把卖点合并，并保证每个卖点仍有独立镜头和清楚的论证关系。

### 4. 设计发布会式叙事

默认采用 4–5 个可独立生成的镜头：

1. **产品揭幕**：锁定身份与高级质感。
2. **问题或压力出现**：呈现雨水、噪音、冲击、热量等挑战。
3. **功能介入**：用直接实验、对照或可信示意展示变化。
4. **结果与用户利益**：让环境或使用状态变得可感知。
5. **Hero packshot**：产品完整、结构稳定、Logo 稳定地定版。

坚持“一镜一个主动作、一镜一个主要信息”。15 秒内不要机械塞入 7 个复杂镜头。镜头之间用动作、形状、光线或声音进行 match cut，而不是依赖模型生成可读字幕。

可以在 15 秒整片创意中设计 6–7 个短促视觉节拍，但实际生成时要按 3–4 个语义连续的 H3 片段拆分，避免一次调用承担过多切镜、产品状态和物理效果。每个片段内部仍保持一条清楚的因果动作链。

### 5. 编写逐镜生成包

按 [output-template.md](references/output-template.md) 输出。每镜必须包含：

- 信息目的和建议时长。
- 引用素材与产品状态。
- 首帧或关键帧提示词。
- 视频运动提示词。
- 图像模型 `gpt-image-2-vip`、图像分辨率 4K、视频模型 `MiniMax-H3` 与视频分辨率 `768P`。
- 产品连续性锁和负面约束。
- 镜头运动、转场、环境音、音效，以及可选旁白或后期字幕。

每一条首帧提示词、关键帧提示词、逐镜视频提示词和可选整片合并提示词，都必须把下面这句话原样放在最前面，不得改写、缩短或移到中后段：

```text
所有镜头中产品身份以 【参考图】为准，产品外观、Logo 位置、包装式正面识别点和结构比例不得随机变化
```

提示词应锁定产品外观、Logo、比例、结构和材质边界，并写清物理元素如何出现、作用于哪里、产生什么可观察变化、如何结束。不要只写“电影感、高级、震撼”。

提示词默认采用三层结构：1）核心创意与商业摄影基调；2）带时间码的画面过程，逐段写清景别、动作来源、作用点、可见结果、转场与结束状态；3）全片连续性、事实边界、生成文字和廉价 CG 禁止项。优先使用“撞击、分裂、滚落、扩散、导出、衰减、收束、退开”等可观察动词，少用无法执行的抽象形容词。

让光线负责揭示材质、结构与状态变化；让水膜、水珠、气流、冲击、机械动作、屏幕响应或声画节拍承担 match cut。最终必须让挑战元素和特效逐渐退场，回到产品完整、清晰、结构稳定的 Hero packshot。

### 6. 生成与组装

仅在用户明确要求实际生成时执行外部任务。需要补充关键帧或首尾帧时，先用 `gpt-image-2-vip` 的 4K 档生成或编辑；再用 `MiniMax-H3` 的 `768P` 档逐镜生成视频，不要求模型一次完成整条多镜头视频。每次只传当前镜头需要的产品视角和辅助参考，保存任务 ID、版本、实际模型和分辨率。

默认模型不可用或镜头在一次针对性重试后仍失败时，先报告失败并提供本地回退方案；未经用户明确同意，不切换到可灵、Seedance 或其他生成模型。

先评估产品一致性和卖点可读性，再选片。统一色彩、镜头节奏和声音后组装；字幕与参数文字在后期添加，不把乱码风险交给生成模型。

### 7. 做三层质检

- **事实层**：参数、结构、认证和效果是否有依据；隐喻是否被误写成证明。
- **传播层**：观众能否说清“什么功能解决了什么问题”，而不只觉得画面好看。
- **生成层**：产品外观、Logo、比例、结构、材质、镜头动作和物理效果是否连续可信。

失败时只重做问题镜头。若视觉母题盖过产品，先减少特效和动作数量，再提高产品在画面中的稳定占比。

## 固定输出结构

1. **任务摘要与假设**：同时列出 `gpt-image-2-vip 4K`、`MiniMax-H3` 和 `768P` 默认设置。
2. **素材映射与产品身份锁**。
3. **卖点视觉化表**：卖点、用户利益、依据等级、表现类型、视觉变化、风险。
4. **核心创意与发布会叙事弧**。
5. **分镜表**。
6. **逐镜生成包**：逐镜标注图像模型、视频模型和分辨率。
7. **全片连续性、负面约束和声音方案**。
8. **可选整片合并提示词**；它不能代替逐镜生成包。
9. **实际生成记录与成片**，仅在执行模式中提供。

高级商业画面语法见 [premium-commercial-visual-grammar.md](references/premium-commercial-visual-grammar.md)，设计核心创意与提示词时必须读取。耳机降噪的完整示例见 [example-headphones.md](references/example-headphones.md)；户外服装的环境实验示例见 [example-outdoor-apparel.md](references/example-outdoor-apparel.md)。只在对应品类或需要类比时读取，不要照抄产品事实。

## 路由边界

- 若核心要求是保留某条原视频的动作、构图、场景和节奏，只替换人物、服装、产品或 Logo，改用 `kaola-fuke`。
- 若任务是商品图出偏销售转化的四宫格分镜，留给未来的 `kaola-daihuo`；本 Skill 聚焦功能解释和卖点论证。
- 原视频只作为风格参考、不要求保持其结构时，仍按本 Skill 从零设计卖点片。
