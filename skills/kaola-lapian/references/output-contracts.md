# 拉片输出契约

## 固定图像交付

每个完成拉片的项目同时交付：

- `storyboard-grid.jpg`：逐秒纯画面，按全局顺序从左到右、每行六张。
- `storyboard-script-grid.jpg`：与纯画面图使用完全相同的逐秒帧、编号和排列，每张图片下方依次放置对应的 `时间`、`画面`、`脚本`。
- `storyboard-order.json`：纯画面顺序映射。
- `storyboard-script-order.json`：图文分镜顺序及对应拉片段映射。

图文分镜内容必须来自最终版 `lapian-base.md`。同一时间段覆盖多张逐秒帧时保留重复文字，不为减少重复而删帧或改变两张图的对应关系。

```markdown
- 帧率：
- 音轨：有 / 无
- 抽帧间隔：
- 转写引擎：SenseVoice Small

时间: "0:00-0:02"
画面: "只写实际可见主体、动作、场景、景别与必要运镜。"
脚本: "只写该时段实际人声；没有人声写无。"
```

带货路由文件可以完整复用基础拉片，但文件顶部必须注明：

```text
下游 Skill: kaola-daihuo
输入性质: 原视频忠实拉片，尚未进行卖点与投放适配
待确认: 发布平台；TikTok 市场与语言；商品卖点；时长；画幅；视频模型；分辨率；背景音乐；动作真实声；转场特效声
```
