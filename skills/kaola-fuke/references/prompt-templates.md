# 逐段提示词模板

不要把本页所有模板一次性拼进一个提示词。每段只组合“全局不变量 + 当前替换目标 + 当前镜头类型 + 禁止项”。方括号内容必须根据实际分镜替换。

## 全局不变量

```text
视频编辑任务。以输入视频片段为唯一结构底片，严格保持原片的镜头起止、人物数量、人物动作、手势、物体数量与位置、遮挡关系、场景、构图、机位、镜头运动、光照方向、剪辑节奏和时长。

只替换下列明确指定的属性：
[人物 A 的身份 → @图片1]
[人物 A 的服装 → @图片2]
[原产品 → @图片3]

不重新创作剧情，不新增或删除镜头、人物、产品或道具，不改变背景、动作、站位和镜头顺序。未列入替换映射的内容全部保持原样。

画面中不生成字幕、逐词字幕、标题、贴纸、水印或其他文字。台词通过人声音轨朗读，不用画面字幕替代声音。
```

## 人物互动段

```text
这是人物互动镜头。原片中共有 [N] 人，生成后仍须保留 [N] 人，人物的站位、身体动作、头部方向、表情强度、手势、互动关系和出入画时间保持不变。

只将 [人物 A] 的 [身份/服装] 替换为 [参考素材 ID]；其他人物身份与服装不变。[若产品也需替换，写明产品与参考 ID。]

禁止合并人物、删除背景人物、新增路人、改变动作、改变视线方向或重写剧情。
```

## 人脸身份段

```text
只将 [人物 A] 的身份特征替换为 @图片1。保持原片的头部角度、表情强度、口型节奏、视线、发型大轮廓、光照方向、身体姿势、镜头构图与其他人物不变。身份在每一帧中连续稳定，不改变年龄表现、体型或动作。
```

如用户未要求保留发型，可把“发型大轮廓”加入允许改变项；不要默认修改。

## 服装段

```text
只把 [人物 A] 的服装替换为 @图片2，并保持参考服装的颜色、版型、图案、Logo 位置、材质边界和层次。保持原人物的身体轮廓、姿势、手臂动作、走位、衣物受力方向、镜头角度、光照与背景不变。服装应随原动作自然形变，不遮住原本可见的手、脸或产品。
```

## 产品或道具交互段

```text
只将原片中的 [原产品/道具] 替换为 @图片3。保持产品数量、大小、比例、位置、朝向、运动轨迹、手持方式，以及与手和其他物体的遮挡关系。保持人物动作、背景、镜头运动和时长不变。锁定 @图片3 的轮廓、结构识别点、Logo 位置和材质边界。
```

## 手部操作段

```text
这是只有手、手臂与 [产品/道具] 的操作特写。严格保持手的数量、手势、操作方向、节奏、物体位置、遮挡、机位、背景和时长。只替换 [目标产品/道具] 为 [参考素材 ID]。

禁止出现人物脸、头部、上半身或全身；禁止改变手部动作、补充展示动作或移动物体位置。
```

## 产品特写段

```text
这是产品特写。只把原产品替换为 @图片3，并严格保持原片的产品数量、屏幕占比、比例、角度、位置、旋转方向、手的位置、手持姿势、背景道具、光照方向、构图与运镜。

若原片只有手和产品，生成后也只能有手和产品。禁止出现人物脸、身体、额外产品、随机包装、随机文字或新的展示动作。
```

## 虚焦人脸修复：产品聚焦替换图

仅在普通生成已经失败、质检发现原身份残留，或用户明确反馈虚焦人脸问题后使用；首次生成不得主动套用。

```text
图像编辑任务。以原始帧为构图底片。把前景旧产品替换为 @图片3，把背景人物完整身份替换为 @图片1。

视觉中心只放在前景产品：清晰呈现产品轮廓、结构识别点、材质、按钮、屏幕和接口，保持原手势与遮挡关系。背景人物只作为景深层次，整张脸和头发保持连续、自然、真实的浅景深虚焦；身份来自 @图片1，但五官不得锐利清晰，不得残留原人物身份，不得出现贴脸硬边、双脸或马赛克观感。

保持原场景、光照方向、机位和色调。无字幕、无标题、无水印、无随机文字。
```

## 虚焦人脸修复：图生视频

仅使用已经通过质检的产品聚焦替换图。

```text
以已确认的产品聚焦替换图为唯一首帧和人物、产品外观参考。产品始终是唯一清晰焦点，背景人物的脸全程保持同一身份和一致的自然浅景深虚焦，镜头不得转焦到人脸。

运镜：[例如 2 秒内缓慢推近 4%，同时轻微向右横移；保持细小、自然的手持呼吸感。]
产品动作：[例如双手保持原握姿，产品绕竖轴顺时针旋转约 12 度，数显和按钮始终朝向镜头，手指遮挡随旋转自然变化。]
动作节奏：[例如前 0.4 秒稳定展示，0.4–1.5 秒完成小角度旋转，最后 0.5 秒停住定版。]
镜头时长：[N 秒]。

禁止改变产品结构、比例、颜色和按钮位置；禁止补出清晰人脸、改变人物身份、生成夸张口型或新增动作；禁止字幕、标题、水印和任何画面文字。
```

## 通用负面约束

按当前片段删减后使用：

```text
禁止新增人物，禁止删除人物，禁止改变人物数量、动作、表情方向、手势、站位和口型节奏；禁止新增镜头、改变镜头角度、背景、场景、运镜、剪辑节奏和时长；禁止改变产品数量、比例、位置、角度、Logo 和遮挡关系；禁止字幕、逐词字幕、标题、贴纸、随机文字、水印、闪烁、形体融化、额外手指、身份跨帧漂移和画面无关美化。台词必须通过人声音轨朗读，不在画面中显示。
```

## 声音模式 A：原声回贴

```text
声音模式为“原声回贴”。保持原片人物的口型节奏、表情和头部动作，模型音轨不作为最终声音。生成后只取画面，最终按原时间线合回原片人声、音乐与环境声。画面无字幕、无逐词字幕、无标题、无水印和其他文字。
```

## 声音模式 B：H3 原生台词

每段只填写本段实际出现的说话人和准确台词：

```text
声音模式为“H3 原生台词”。保留本段模型生成的视频与音轨，不使用原片人声覆盖。

生成前确认状态：[台词已确认 / 待确认]
原片识别语言：[语言；置信依据]
用户确认语言/口音：[语言/口音]
说话人依据：[原片可见人物、原片声音、替换人物参考]

说话人：[人物 A]
语言/口音：[用户已确认的语言/口音]
声音表现：[根据原片人物和替换人物参考推断并经用户确认的性别表现、年龄感、音高与质感；不得套用年轻女性或其他默认人设]
语气与情绪：[自然、兴奋、克制等]
语速与停顿：[描述]
朗读时间：[00:00.000–00:03.200]
准确台词：“[本段台词]”

人物必须逐字准确朗读引号内台词，不增加、删除、替换、重复或改写任何字词；不得出现第二个声音、随机旁白、背景人声或无关语言。口型与每个音节同步，保持原片的头部角度、表情、视线、动作和镜头节奏。

环境声：[来源、时间点和强弱]
动作声：[来源、时间点和强弱]

台词只从音轨出现。画面无字幕、无逐词字幕、无标题、无水印、无随机文字和其他画面文字。

只调用 MiniMax-H3 视频生成 API，由 H3 在生成画面的同时直接生成上述人声、口型、环境声和动作声。禁止调用 TTS、音色合成、声音克隆、配音或其他独立音频 API；禁止传入 reference-audio。
```

### H3 原生台词：无可见口型段失败后的解耦回退

仅当产品特写、手部操作、空镜、B-roll 或画外音经过一次针对性短段重试仍失败，并且用户明确同意解耦回退时，使用此附加模板：

```text
本段没有需要与台词同步的可见嘴部。画面成片以已通过质检的锁定画面母版为准，不因台词改变而重新生成镜头、产品动作、手势、物体运动、运镜或转场。

仍只调用 MiniMax-H3 视频生成 API 原生生成已确认台词、环境声与动作声。任务返回后仅提取 H3 模型音轨，丢弃 H3 返回的视频流；把该音轨按原时间线合到锁定画面母版。禁止调用 TTS、音色合成、声音克隆、配音或其他独立音频 API。

关键动作状态链：[起始状态] → [触发动作] → [结束状态]
验收时间点：[时间码与应出现的状态]
```

## 特效变更表与提示词

只有用户明确要求修改原片特效时使用；默认复刻不填写。

```text
特效变更确认状态：[已确认 / 待确认]
[00:00.000–00:01.200] 原特效：[描述] → 新特效：[描述]
服务的动作或卖点：[唯一目的]
重复限制：[本效果全片最多 N 次；不得在其他片段重复]
强度与持续时间：[克制/中等/强；N 秒]
触发与物理关系：[由哪个产品动作触发，如何出现与消散]
转场方式：[描述]
声音：[whoosh/机械声/环境声/无；时间点和强弱]

严格只实现以上已确认特效。未列入变更表的镜头沿用原片；禁止临时新增粒子、光扫、能量环、闪白、震动或重复效果。
```

## 提示词交付格式

```markdown
### S01 · 00:00.000–00:03.200

- 镜头类型：人物互动
- 底片：@视频1 的 S01
- 引用素材：@图片1、@图片2、@图片3
- 图片能力：系统内置；仅生成新的虚构人脸参考图时建议 GPT Image Two
- 视频模型：MiniMax-H3
- 视频分辨率：768P
- 目标：替换人物 A 的脸、上衣与手中产品
- 声音模式：原声回贴 / H3 原生台词
- 说话人、时间码与准确台词：……
- 声音表现：直接写入 H3 视频提示词的语言、年龄感、语气、音高与语速描述
- 声音确认状态：台词 / 语言 / 说话人表现分别为已确认或待确认
- 特效变更确认状态：无变更 / 已确认 / 待确认
- 最终音轨：合回原声 / 保留 H3 模型音轨
- 正向提示词：……
- 负面约束：……
- 推荐处理：底片视频编辑
- 回退：在举起产品前后拆为 S01a/S01b；产品遮挡段改局部合成
```
