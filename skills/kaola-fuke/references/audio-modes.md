# 复刻视频声音模式

## 选择门

原片包含台词且用户尚未选择时，在任何付费生成前询问：

```text
原片包含台词。声音请选择：
1）原声回贴：视频生成后使用原片人声、音乐和环境声；
2）H3 原生台词：把原台词写进各段提示词，让人物在生成视频时同步说出台词并生成环境声。
```

选择 2 后不再询问或调用独立音色服务。把语言、年龄感、语气、情绪、音高和语速作为 H3 视频提示词中的“声音表现”描述，由 MiniMax-H3 视频 API 在生成画面的同时直接生成新的人声音轨。不得调用 TTS、音色合成、声音克隆、配音或其他音频 API，不得传入 `reference-audio`。

把声音模式和声音表现描述写入执行包。未选择时停止在执行包，不调用付费模型。

选择 2 不等于已经确认台词。每一次 H3 付费视频生成或重试前，必须展示并确认以下内容：

```text
声音确认单
- 片段与时间码：
- 说话人 ID：
- 准确台词：
- 原片识别语言：
- 本次确认语言与口音：
- 说话人依据：原片可见人物 / 原片声音 / 替换人物参考
- 本次确认的性别表现、年龄感、音高与声音质感：
- 语气、语速与停顿：
- 相比上一版的台词改动：无 / 逐条列出
- 用户确认状态：待确认 / 已确认
```

只有用户明确确认当前版本的台词、语言和说话人表现后，状态才能改为“已确认”。任一文字或声音设定发生变化后，状态自动回到“待确认”。

## 模式 A：原声回贴

1. 按画面结构切段并生成。
2. 生成片段只取视频流；不依赖模型台词是否正确。
3. 统一画面参数、精确裁回原时间线并拼接。
4. 合回原片完整音轨，检查口型、动作音、音乐节拍和转场点。

适用于需要最大程度保留原说话人、原表演、原音乐和声音节奏的复刻。

## 模式 B：H3 原生台词

### 默认保持原生视听耦合

H3 原生台词模式默认保留同一次生成的视频流与模型音轨。无论是否出现嘴部，都先以动作正确的视频为唯一底片，让 H3 在保持原镜头的同时原生生成台词：

- **露脸口型段**：按完整短句切短，锁定头部、表情、动作和镜头，同时检查口型与画面结构。
- **无口型动作段**：按一个具有明确物理结果的动作切短，把“起始状态 → 触发 → 运动轨迹 → 结束状态”写成逐时间约束，同时保留 H3 返回的视频流和音轨。

若一个长段同时包含露脸说话和无口型 B-roll，必须在镜头边界拆开，避免台词条件连带重写全部画面。无口型动作段经过一次针对性短段重试仍失败时，停止继续付费；可以向用户提供“锁定画面、只取 H3 视频 API 原生音轨”的解耦回退，但不得默认采用。以上路径都不调用 TTS、音色合成、声音克隆或独立配音 API。

### 台词准备

1. 从原片提取带时间码台词，区分说话人 A、B 等；不确定字词必须先让用户确认。品牌、型号、数字、单位与专有名词单独复核。
2. 按完整短句、换气点和语义停顿切段，不在词语、音节或强连续口型中间切断。
3. 每段记录：开始与结束时间、说话人、原台词、语言/口音、年龄感、情绪、语速、音量、是否有重叠对白、环境声和动作声。
4. 台词长度必须适配片段时长；过长时先调整语速或切分，不擅自删词、改词或补词。
5. 语言默认沿用原片识别语言，但仍须用户确认；识别不确定时不得猜测后生成。
6. 性别表现、年龄感和声音质感依据原片说话人物及替换人物参考推断并交由用户确认，不设“年轻女性”或其他通用默认。两类依据冲突时直接询问用户。
7. 完成声音确认单；状态不是“已确认”时停止，不调用 H3。

### H3 提示词

- 把本段唯一允许出现的准确台词放进引号，写明“逐字准确朗读，不增加、删除、替换或重复任何字词”。
- 写明说话人 ID、声音表现、语气、语速、停顿位置、开始时间和结束时间；这些描述直接交给 H3 视频模型，不是独立音色合成参数。
- 锁定原片头部动作、表情、口型节奏和视线；要求口型与每个音节同步。
- 写明环境声和动作声的来源、强弱与时间点；禁止随机旁白、第二声音、背景人声和无关音乐。
- 继续加入“无字幕、无逐词字幕、无标题、无画面文字”，尽量让台词只从音轨出现。用户未把无字幕设为硬要求时，模型仍生成但与确认台词逐字一致、同步稳定且不遮挡主体的字幕可容错通过；用户明确要求无字幕时不得容错。
- 只调用 MiniMax-H3 视频生成 API。禁止调用 TTS、音色合成、声音克隆、配音或其他独立音频 API；禁止传入 `reference-audio` 来生成或复刻声音。

### 拼接

1. 默认保留每个 H3 片段同一次生成的视频流和模型音轨。只有用户在失败后明确同意解耦回退时，无口型段才丢弃 H3 视频流并改用锁定画面母版。
2. 统一采样率、声道、响度和编码；在无台词停顿处切分，并对相邻环境底噪做短交叉淡化，避免爆音和突变。
3. 不把原片人声重新覆盖到模型音轨。若用户要求保留原音乐，先分离或取得无对白音乐层；不得直接混入含原人声的完整音轨造成双人声。
4. 检查跨段声音表现、口音、音量、空间感和背景环境是否连续。

### 质检与停止条件

- 逐字核对台词：漏字、改字、重复、乱序和新增内容均不通过。
- 检查说话人归属、多人串音、口型同步、声音表现、情绪、语速和停顿。
- 检查是否生成字幕、随机文字、旁白、背景人声或双人声。字幕按分级规则处理：明确要求无字幕则任何字幕失败；否则准确同步、不遮挡主体的模型字幕可通过，错词、漏词、旧字幕残留、乱码或额外文字仍失败。
- 无口型段还要逐帧对照动作正确的参考底片，确认关键动作的起始、触发、轨迹和结果没有因生成台词而改变。
- 单段允许一次针对性重试。仍失败时停止继续付费生成，让用户选择原声回贴或暂不继续；不得自动调用独立配音、TTS 或音色合成 API，不得静默切换。
